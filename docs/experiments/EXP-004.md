# EXP-004 — Smooth Brock–Hommes geometry (GGN vs Hessian, horizon dependence)

**Status:** done
**Authoritative code commit:** `6ff8031` (run `outputs/EXP-004/*_6ff8031/`; deterministic)
**Supports:** C03, C09 (in BH); characterizes RQ4 (differentiation-horizon dependence)

## Question

In the actual Brock–Hommes model (correct large-β regime), does the MMD GGN
predict the local loss geometry, and how does that depend on the **differentiation
horizon**? EXP-000 showed the full-horizon GGN explodes in the chaotic regime, so
the horizon is a first-class variable here.

## Method

BH in prior-scaled `z`, R=1.01, σ=0.04, two dynamical intensities: β=50 (complex)
and β=80 (chaotic). Finite-feature (RFF) mean-embedding `η̂(z)`; loss
`L_feat(z)=½‖η̂(z)−η_y‖²`. `G = Ĵ_ηᵀĴ_η` (plug-in), `H = ∇²L_feat`. float64, M=128.

Three parts:
- **A — horizon dependence of `G`:** for `grad_horizon ∈ {1,5,10,20,50,full}`,
  report the feature-Jacobian norm (explosion), `G` spectrum, effective rank, cond.
- **B — predictive validity vs horizon:** at each horizon, the GGN quadratic
  `½α²λ₁(H_g)` along `G`'s leading eigenvector vs the actual (forward,
  horizon-independent) local loss change `ΔL(α)`; validity radius at prespecified
  `τ=0.10` and α-grid. → which horizon makes `G` predictive.
- **C — `H` vs `G` at nonzero residual (working horizon):** target along the stiff
  direction, `δ∈{0,0.3,0.8}`; report `R=H−G`, `R/‖H‖`, `e_curv`, principal angles.
  (At `δ=0` the reference is self-consistent so `H=G`.)

## Result

**C — GGN vs exact Hessian (working horizon).** At the fit (δ=0, residual 0)
`H = G` to machine precision (`‖H−G‖/‖H‖ ~ 1e-16`, angle 0°). Away from the fit
`R = H−G` grows with residual: `R/‖H‖` 0 → 0.51 → 1.23 (β=50), → 1.00 (β=80);
leading H–G angle up to 58°; `e_curv` up to 3.7. So in BH the GGN equals the
exact Hessian **only at/near the fit** — same residual-curvature mechanism as
EXP-002, now in the real ABM.

**A/B — differentiation-horizon dependence (RQ4, the novel result).** Truncating
the horizon strongly biases the GGN, and full-horizon curvature explodes in chaos:

| | β=50 (complex) | β=80 (chaotic) |
|---|---|---|
| `‖J_η‖` (h=1 → full) | 0.009 → 0.77 | 0.004 → **1.27e4** |
| `λ₁` (h=1 → full) | 8e-5 → 0.38 | 1.5e-5 → **1.5e8** |
| leading eigvec angle vs full (short h) | ≤ 7° (**direction robust**) | 32–48° (**direction distorted**) |

Truncation **under-estimates curvature magnitude by orders of magnitude** at every
β; it **preserves the leading direction in the complex regime but distorts it in
chaos**. The full-horizon (true) curvature is dominated by chaotic sensitivity
(λ₁ ~ 1.5e8 at β=80).

**Predictive validity radius (fine α-grid, τ=10%).** Only the full-horizon GGN is
ever predictive, and only over a **tiny** radius: ρ ≈ 0.003 (β=50), ρ < 1e-4
(β=80). The local quadratic geometry is *correct* but predictive only in a small
neighborhood — shrinking toward zero as chaotic intensity rises.

## Claim impact

- **C03 → supported conditionally (now extended to BH):** `H = G` at the BH fit
  (residual 0) to 1e-16; `R` grows off-fit. Was toy-only (EXP-002); now shown on
  the actual ABM.
- **C09 → supported conditionally, with a strong BH caveat:** the GGN predicts
  local loss only over a very small radius (≈0.003 at β=50), shrinking to ~0 in
  the chaotic regime.
- **RQ4 (new, unregistered):** the GGN depends materially on the differentiation
  horizon — magnitude always biased by truncation, direction distorted in chaos,
  full-horizon curvature explosive. **EXP-004b confirms this is intrinsic**
  (representation-independent — the explosion is in `∂X/∂θ`, not the observable).
  Candidate for a dedicated claim + EXP-008.
