# EXP-007 — SIR observation-design study

**Status:** done
**Authoritative code commit:** `4adb5c6` (run `outputs/EXP-007/*_4adb5c6/`; deterministic)
**Supports:** C13

## Question

EXP-006 showed the intervention value is unidentified because the lockdown strength
`f_lock` is barely constrained by incidence. Which **added observation** recovers
information in that weak direction and collapses the policy uncertainty?

## Method

Smooth SIR (EXP-005/006 setup). Three observation designs, each a whitened
representation `m(z)`: (1) incidence only; (2) incidence + prevalence; (3) incidence
+ **compliance** (the effective transmission rate `β_eff(t)` observed over a window
spanning the lockdown transition, t∈[0.3,0.7], σ=0.02). For each: GGN `G=J_mᵀJ_m`,
prior-relative spectrum / `d_data`, the sloppiest direction's loading, and the
in-fit range of the counterfactual intervention value (EXP-006 Lagrange sweep,
budget 2 nats). Design 1 reproduces EXP-005's spectrum exactly (local-SIR check).

## Result

| design | d_data | smallest λ | sloppiest | intervention in-fit range |
|---|---|---|---|---|
| incidence only | 3 | 8.9e-6 | f_lock | **[0, 2181] cases** (width 2181) |
| + prevalence | 3 | 1.3e-5 | f_lock | [0, 1821] — barely helps |
| **+ compliance** | **5** | **10.0** | gamma | **[69, 108] cases** (width **38**) |

- **Compliance data lifts the weakest direction by ~10⁶×** (λ 8.9e-6 → 10), takes
  the data-dominant dimension from **3 to 5** (all directions informed), and
  **collapses the policy uncertainty 57×** — turning "the data can't tell whether
  the lockdown averts 0 or ~2180 cases" into "the lockdown averts ~90 (69–108)."
- **Redundant observation doesn't help:** adding prevalence (which carries the same
  epidemic-curve information as incidence) leaves f_lock sloppy and the policy
  uncertain. Only the observation that measures what incidence is *blind to* — the
  lockdown transmission itself — recovers the weak direction.

## Claim impact

- **C13 → supported conditionally:** a targeted added observation (compliance /
  transmission across the lockdown transition) measurably increases information in a
  previously weak direction (`f_lock`: λ 8.9e-6 → 10) and collapses the associated
  policy uncertainty 57×; a redundant observation (prevalence) does not. The GGN
  diagnostic is *actionable* — it identifies which observation to add.
- Scope: smooth deterministic SIR, this θ* and noise scales (compliance σ=0.02).
