## Question

Can the MMD GGN `G = J_ηᵀ J_η` be estimated from simulator feature Jacobians,
and how do the estimators behave?

## Method

Controlled Gaussian location-scale simulator (prior-scaled `z`), frozen RBF
random Fourier features with a **closed-form** analytic reference `G_ref`.
Estimators: PSD plug-in `Ĝ_V`, cross-seed `Ĝ_U=(SᵀS−Q)/(M(M−1))`, and labeled
scalar OPGs (comparison). `B=200` batches, main + near-degenerate regimes, float64.

## Result

- Reference validated: closed-form `η` vs MC `2.4e-3`; `J_η` vs finite-diff `3.9e-11`;
  finite-D `G_ref → G_RBF` (exact kernel) `0.084→0.028` over D.
- Plug-in bias decays `~1/M` and matches predicted `Ĉ/M` inside the 95% CI for M∈{8…128}.
- Cross-seed bias compatible with zero at all M; indefiniteness `0.94→0` by M≥32.
- Top-2 subspace recovered to ≤5° for M≥16.
- OPG=0 at exact match while `G_ref≠0`; residual-dependent and shape-distinct otherwise.
- 181 tests passing.
