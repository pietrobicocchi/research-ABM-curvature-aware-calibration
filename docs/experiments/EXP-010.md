## Question

Is the prior-relative local GGN geometry available *during* calibration, or only as
an offline snapshot at the optimum? As gradient descent moves from a displaced
start to the smooth SIR fit, does the leading GGN eigenspace stay aligned and does
the data-dominant dimension stay fixed at a loss still far above convergence — the
property finite-difference / surrogate-network Hessians (offline, single snapshot at
the fit) lack?

## Method

Smooth SIR from EXP-005 **unchanged** (`T, m, SIGMA_DATA, Z0=0`, deterministic,
float64). Data `y = m(Z0)`, loss `L(z) = 0.5·Σ(m(z)−y)² / SIGMA_DATA²`. Start at a
prior-typical displacement `z_init = 1·ones(5)` (‖z‖≈2.24, initial loss 9212 =
5051× the converged value). Descend with Adam (lr 0.05, 800 steps — Adam, not
L-BFGS, for a smooth path that handles the ~1e9 GGN condition number), checkpointing
every 8 steps.

At each checkpoint recompute the prior-relative GGN `G(z_t)=J_m(z_t)ᵀJ_m(z_t)/σ²`
(z prior-whitened ⇒ compare λ to 1), eigendecompose, and record: profiled loss;
the spectrum λ₁…λ₅; `d_data = #{λ>1}`; the leading-`k` (k=1,2,3) subspace principal
angle to the **converged endpoint** ẑ (the honest self-contained reference — Z0 is
unknown in a real calibration). float64, deterministic.

## Result

Descent 9212 → **1.82** nats (5051× drop, endpoint below the 2-nat good-fit budget).

| read | value |
|---|---|
| `d_data` along the entire path | **3, constant** — pinned from step 0 (loss 5051× final) |
| leading-2 eigenspace angle to final, at step 0 | **7.9°** (already <10° at the displaced start) |
| leading-2 angle <5° reached by | loss 926× final (step 8) — still far above convergence |
| leading-3 eigenspace, whole path | within ~10° of final (brief early transient ≤10° near step 20), decaying monotonically to **<0.1°** at the fit |
| data-dominant eigenvalues (λ₁,λ₂,λ₃ > 1) | **stable** along the path; only the deep-sloppy tail (λ≪1) moves |
| endpoint ẑ | `t_lock≈1.41, f_lock≈1.44` still displaced (the sloppy directions the data does not recover) yet loss 1.82 — a good fit |

The prior-relative geometry — the directions the diagnostic calls stiff/sloppy and
the data-dominant dimension — is a **stable feature of the whole calibration basin**,
not a fragile property of the exact optimum. A displacement scan corroborates this
beyond the descent path: at up to a 4-prior-std displacement in every coordinate
(loss ~4×10⁴, 10⁴× the converged value) the leading-2 eigenspace stays within ~10°
of its converged orientation and `d_data` stays at 3. So there is no "lock-in
event" to report — the honest, stronger statement is path-wide stability, which is
exactly what licenses reading the diagnostic *during* calibration rather than only
after convergence.

**Honest scope.** One model (smooth deterministic SIR), one descent, one `z_init`.
A single trajectory does not establish path-independence, and the endpoint reference
is itself displaced in the sloppy directions (consistently with those directions
being data-underdetermined — the same mechanism as the policy chapter). The spectrum
does move along the path (stiff λ grow, sloppy tail plunges after an early
transient); it is the eigen*vectors* and `d_data` that are stable.

  post-hoc snapshot at the fit. This is the evidence behind the Background
