# EXP-005 — Smooth SIR posterior validation

**Status:** done
**Authoritative code commit:** `7ba9447` (run `outputs/EXP-005/*_7ba9447/`; deterministic)
**Supports:** C10, C11

## Question

Does the prior-relative GGN agree with the true local generalized posterior?
I.e. do the GGN eigen-directions and the GGN-Laplace covariance match the actual
posterior contours (C10), and does the profiled posterior energy match the GGN
quadratic along stiff and sloppy directions (C11)?

## Method

Smooth **deterministic** mean-field SIR (`models/sir`, σ_obs=0 → expected
incidence), Gaussian-noise loss `L(z)=½‖m(z)−y‖²/σ_data²` (σ_data=150), prior-scaled
`z~N(0,I)` via a documented transform `T(z)` (log-normal β,γ; logit-normal
I0,t_lock,f_lock; θ*=T(0)=(0.4,0.1,1e-3,0.4,0.5)). Data `y=m(0)` ⇒ mode at z=0,
residual 0. Generalized-posterior weight w=1 ⇒ prior precision I.
- GGN `G=J_mᵀJ_m/σ²`, exact Hessian `H`, Laplace precision `P=G+I`.
- **Reference posterior:** self-normalized importance sampling (Laplace proposal,
  1.3× variance-inflated, N=4e5) — robust for this ill-conditioned near-Gaussian
  posterior where MCMC mixes poorly (cond ~2.5e4).

## Result

- **`H = G` at the mode** (R/‖H‖ = 2.1e-16, residual 0).
- **Prior-relative spectrum** `[2.5e4, 135, 2.78, 5.3e-3, 8.9e-6]` ⇒
  **data-dominant dimension `d_data = 3`** (3 stiff, 2 prior-dominated/sloppy).
- **C10 — GGN-Laplace vs true posterior:** leading posterior axes agree to
  **0.68°/1.0°** (top-1/top-2 principal angle); covariance relative error **25%**;
  marginal widths match to ≤5% for 4/5 parameters (t_lock 20%, the one mildly
  non-Gaussian direction, skew 0.51); posterior mean shift 0.23.
- **C11 — profiled posterior energy** (α in each direction's posterior-std units):
  matches the GGN quadratic `½α²(λ+1)` to **<0.5%** along both the **stiff**
  (max rel err 0.004) and **sloppy** (0.001) directions.
- IS ESS ≈ 1.8% (~7.4k effective) — sufficient for the covariance/orientation.

**Contrast with EXP-004:** on smooth SIR the GGN diagnostic works cleanly (the
positive inferential result); in chaotic BH it broke down (sensitivity-dominated).

## Claim impact

- **C10 → supported conditionally:** the prior-relative GGN captures the local
  posterior orientation (axes ~1°) and the data-dominant dimension on smooth SIR;
  mild non-Gaussianity in one direction (t_lock, 20% width).
- **C11 → supported conditionally:** profiled posterior energy matches the GGN
  quadratic to <0.5% along stiff and sloppy directions.
- Scope: smooth deterministic SIR, near-Gaussian posterior, float64. Not yet:
  discrete/stochastic SIR, chaotic regimes, strongly non-Gaussian posteriors.
