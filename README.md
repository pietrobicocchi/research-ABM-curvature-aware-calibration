# What Do the Data Identify? — code

Code for "What Do the Data Identify? A Practical Identifiability Diagnostic for
Differentiable Agent-Based Models". The diagnostic is the Gauss–Newton matrix
G = J_mᵀ W J_m of a discrepancy-based calibration objective, formed from first-order
derivatives of a differentiable simulator. Its eigenvectors are the parameter
combinations the data constrain, and its eigenvalues measure how strongly. The
repository reproduces every figure (1–8) and every number in the paper on a CPU
laptop: the mean-field SIR validation against a sampled posterior and a
finite-difference Hessian, the lockdown counterfactual and observation design, and
the network SIR experiments with surrogate gradients. All data are synthetic and
generated by the code, and all computations run in float64.

## Requirements and installation

Python 3.12. The exact package versions used for the saved results are pinned in
`requirements.txt` (JAX 0.4.30, CPU).

```
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The commands below run from the repository root; the Makefile sets `PYTHONPATH=src:.`.

## Quick reproduction (from saved results)

```
make figures      # about 25 s
```

plots every figure from `results/` into `figures/<name>.pdf`.

## Full reproduction

```
make all          # about 2.5 min on one core of an Intel x86-64 laptop
```

recomputes every result in `results/` and then plots the figures.

Each experiment takes `compute` (writes `results/<name>.json`, and `.npz` where
arrays are needed), `plot` (reads them, writes `figures/<name>.pdf`) or no argument
(both). Its settings, including those of Table 1, are in `configs/<name>.yaml`; the
model settings shared by several experiments are in `configs/mfsir_model.yaml` and
`configs/netsir_model.yaml`.

## Checking the claims

```
make check
```

recomputes every number and statement in the text, captions and appendices, listed
in `claims.yaml`, from the saved results, and prints the paper value, the code value
and whether they agree at the printed precision. `make test` runs a check of the
automatic-differentiation Jacobian against central finite differences (a few
seconds).

## Repository structure

```
src/gndiag/
  models/mfsir.py          mean-field SIR with a smooth lockdown (App. B.1)
  models/netsir.py         network SIR, Gumbel-sigmoid and straight-through (App. B.2)
  diagnostic/ggn.py        eigen-analysis of G (Eq. 5), principal angles
  diagnostic/estimators.py per-seed Jacobians, plug-in G_V (Eq. 14), cross-seed G_U (Eq. 16)
  losses/rff.py            random Fourier features for the kernel mean embedding (Eq. 11)
  losses/mmd.py            median-heuristic bandwidth
  config.py, io.py, plotting.py

configs/                   one configuration per experiment, plus the two model configurations
results/                   saved results
figures/                   figures
claims.yaml, scripts/check_claims.py
tests/test_jacobian.py
extras/brock_hommes/       the diagnostic on the Brock–Hommes model; not used in the paper
```

## Seeds and determinism

There is no global random state: every random draw takes an explicit JAX key
fixed in the configurations (`simulation_key`, `is_key`, `noise_key_offset`,
`base_seed`, graph seeds). The mean-field SIR results are deterministic. On the same
machine and package versions, `make all` reproduces the saved results bit for bit.
On other hardware, results may differ at the level of floating-point round-off,
far below the precision printed in the paper.
